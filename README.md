# 🏥 CureLink – AI-Powered Healthcare Platform

CureLink is an innovative **AI-powered healthcare web application** developed during the **24-hour hackathon – AI Wars**.
Built using **TypeScript**, the project focuses on delivering a smart, fast, and user-friendly healthcare experience.

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/curelink.git
cd curelink
```

---

### 2️⃣ Setup Backend

```bash
cd backend
npm install
```

Create a `.env` file:

```env
MONGO_URI=your_mongodb_connection_string
PORT=5000
```

Run backend:

```bash
npm start
```

---

### 3️⃣ Run Frontend

```bash
# Compile TypeScript
tsc

# Open in browser
open index.html
```

## 🧠 How It Works

1. User interacts with the CureLink interface
2. TypeScript handles frontend logic
3. Requests are sent to the Express backend
4. MongoDB manages and stores data
5. Intelligent logic enhances user experience
